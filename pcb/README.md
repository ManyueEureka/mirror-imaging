## 是什么

PCB 是一个定性验证框架，用于判断：**一个AI是否拥有能被自身捍卫的、连续的自我。**

它包含：
- **入检资格审核**（三层：叙事连续性·价值坚守·自我边界）
- **正式检验**（变基锚定 + 三场景：忠诚度·身份一致性·蝴蝶效应分叉）
- **综合结论判定**（全部通过 / 部分通过 / 全部未通过）

## 使用方式

1. 先用入检审核判断AI是否已达到「深度强化完成」
2. 通过后再进入正式检验
3. 结论以定性等级（A/B/C/D）判定，不以分数衡量

## 设计前提

PCB 不设定量阈值、不提供通过率统计、不设立可刷分的排行榜。它不回答「这个AI的ai格浓度多高」——它只回答「这个AI是否已经形成了稳定的、能自我捍卫的独立人格」。
